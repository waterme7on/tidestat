Before you start

A few useful answers.

Read the documentation →
What do I get before connecting payments?

Live visitors, traffic sources and observed page journeys. Connect your payment flow when you want to link these visits to verified revenue.

Can I try it without connecting my website?

Yes. The interactive demo uses labeled sample data. Explore visitors and revenue journeys before creating an account.

Do I need a developer to install it?

You need access to your website code or someone who can add the browser script. The JavaScript package is currently installed locally; Shopify uses a storefront and pixel adapter, not an App Store installation.

Do I need a paid plan for Revenue Stories?

No. Every plan includes the same analytics features. Paid plans add more websites and a larger monthly event allowance.

What counts toward the event allowance?

Page views and tracked behavior count. Activity heartbeats are excluded, and duplicate events count once. The allowance resets each month in UTC. Events over the limit are not accepted.

What if a payment cannot be linked to a visit?

It stays unattributed. TideStat shows the available evidence without inventing a visitor journey.

Does tracking respect visitor consent?

The SDK supports consent-controlled tracking. Connect it to your consent manager and review the data guide before enabling collection.
