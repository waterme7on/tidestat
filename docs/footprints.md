# 网站足迹：日夜小街区

以 PR #24 合并后的 `9c3652d1c2556e8014c36a94a90c24a4919ba9ed` 为基线，仅更新足迹视图。地球入口、`globe-map.js`、`globe.css`、B 版头像、系统主题控制器、API、采集、数据库和部署配置保持不变。

## 设计和交互

保留 Three.js 立体浏览，将镜面金属底板改为独立哑光站点。页面分区对应可点击的标签和当前人数；同一匿名访客沿用 `avatarSVG(id)`，与地球、列表和详情一致。黑灰夜间使用实际在线分区的暖色窗灯；纸白日间使用低对比灰绿建筑。主题选择共享原有 system/light/dark 设置，不改变相机或访客选择。

默认不自动旋转；保留显式自转按钮，新增俯瞰、展开与 Escape 收起。reduced-motion 时停用装饰旋转与头像移动。点击分区可筛选右侧访客；点击头像或键盘选择访客可查看时间线，并在底部显示访问顺序。每个分区最多展示前三张停留头像（以及选中的头像），标签人数和完整列表仍包含所有人。

## 数据口径

复用原有 SITE、PATH_NODES、访客状态机、90 秒活动窗口和 4 秒 live 轮询，不增加后台接口。节点是既有页面分类，不是完整 URL sitemap。列表展示可获得的真实当前路径。虚线为预先定义的站点关系，不表示这些路线发生过访问；选中后亮线只来自该访客的记录/进行中的跳转，顺序以底部箭头与时间线为准。若记录存在非邻接跳转，直接连接对应节点，不虚构中间页面。

切页中的访客计入目标分区，不在两个分区重复计数。离开的访客不计入在线；无分类访客保留总人数与列表。连接中断保留最近数据并暂停窗灯，初次失败显示未知而非零。移动动画只是导航变化的示意，不是鼠标轨迹或真实加载时间。

## 兼容与资源

沿用 `window.__tide3d.ready/activate/reset` 入口、现有 vendored Three.js 与懒加载。去掉旧 scene 模块中未被默认地图使用的地球仪构造。无新的运行时依赖、外部字体或头像服务。WebGL 不可用/丢失时，使用同一节点、路径、头像与主题的本地 SVG 兼容视图。隐藏页面和离开足迹页时停止该视图帧循环；资源在页面离开时释放，动态路径在取消选择后释放。

## 验证

`node tests/footprints.mjs` 包括纯数据模型与 Chromium/SwiftShader 回归：人数、分区筛选、键盘选中、B 版 SVG 一致性、真实记录路径、日夜切换保留相机、俯瞰与展开、390px 布局、空状态/断线/恢复、转义、WebGL 初始化失败及上下文丢失。原有主题、头像、地球和地球生命周期套件继续运行。截图和 JSON 随 Visual review artifact 提供，访客均为测试数据，不是生产统计。手机视口测试不等于物理手机或 Safari 实测。
