# B：呆萌涂鸦贴纸头像

用用户确认的 **Notionists Neutral** 替换此前的彩色人物头像：黑色手绘五官、奶白圆底，少量淡黄／淡绿底色。没有头发、身体、肤色推断、立体高光或新的发光效果。使用原始素材而非仿绘。素材及来源见 `vendor/notionists-neutral/LICENSE.txt`。

## 修改范围

`visitor-avatar.js` 保持原有同步 `avatarSVG(id)` 接口。地球标记、地图中的多人头像组、侧栏、详情弹窗及平面兼容模式继续调用同一个函数，因此同一访客处处是同一个头像。所有渲染由现有入口接入，无需改变地球相机、人数口径、头像尺寸或交互逻辑。网站足迹的独立画法本轮未改。

生成完全在本地进行；不会向 DiceBear 或任何头像服务发送访客 ID、城市等数据。完整 ID 只用于确定性哈希，绝不插入 SVG 字符串。刷新与切换地区不改变头像；不同 ID 可能碰巧得到同样的造型，头像不是唯一身份凭证，也不代表真实外貌。

## 固定的素材与变体

沿用确认图使用的 DiceBear 9.x Notionists Neutral 素材，固定到 `dc3dc40438791cd0bec9ef50512f2baeed53a633`。精选四组原始路径：4 种眉、3 种眼睛、3 种鼻、4 种嘴型；保持上游 560×560 画布与偏移。奶白为主，淡黄和淡绿作为小范围点缀。

选取的源文件、变体 ID、CC0 美术许可和 MIT 代码许可均随文件保存。路径无需 SVG filter、字体、外链图片或重复 DOM ID，兼容现有 MapLibre 图像纹理及无 WebGL 的平面视图。

底色、数组顺序和哈希算法属于固定的头像映射；后续调整需要显式的视觉版本更新，不应在数据刷新时重新随机生成。

## 验证

`node tests/avatars.mjs` 检查确定性、长 ID、异常字符不泄露为 markup、SVG XML 与小尺寸光栅化、侧栏／弹窗一致性，并生成 32/48/96px 实际 SVG 对比截图。`tests/fixtures/avatar-preview.html` 是只使用固定测试种子的独立预览页，不访问生产统计。

原有 `tests/globe.mjs`、`tests/globe-lifecycle.mjs` 继续覆盖地球渲染、头像点击、同城组、移动视口、离线与空状态、WebGL 降级及网站足迹切换。测试 API 使用固定数据；截图人数不代表线上统计。
