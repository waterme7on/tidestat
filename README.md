# TideStat

实时访客可视化分析 MVP。两个核心视图:

- **世界地图** — 访客按城市落点,光点脉冲表示当前在线密度,新访问涟漪提示,侧栏实时事件流。
- **网站足迹** — 把站点结构画成一座公园(节点=页面,虚线=链接),每位访客是一个步行光点,在页面间移动、停留、离开;点击事件流条目可追踪单个访客的完整时间线。

当前为 MVP:数据由内置模拟器驱动,事件结构(`visitor / pageview / leave` + 城市 + 页面序列)已按真实埋点形态设计,下一步接入真实的采集 SDK 与事件 API。
